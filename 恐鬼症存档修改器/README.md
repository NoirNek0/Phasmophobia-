# 恐鬼症存档修改器

改恐鬼症（Phasmophobia）本地存档的小工具。主要是改钱，顺手把等级也做了。

起因是网上找的修改器要么收费要么带毒，干脆自己把存档格式扒了一遍。

## 使用

到 Releases 下 `恐鬼症存档修改器.exe`，双击就跑，不用装 Python。

**改之前必须把游戏完全退掉。** 游戏开着时改是没用的——退出游戏那一下它会把内存里的旧存档写回去，正好覆盖你改的。程序会检测进程，检测到就不让写。

界面上填金钱和等级，点「应用修改」。存档路径会自动找：

```
%USERPROFILE%\AppData\LocalLow\Kinetic Games\Phasmophobia\SaveFile.txt
```

注意存档**不在** Steam 游戏根目录，在 `AppData\LocalLow` 底下（Unity 的规矩）。找不到的话界面上也能手动选。

写入前会自动备份一份 `SaveFile.txt.bak-20260930-234409` 这种带时间戳的，改坏了改名换回去就行。

## 关于等级

存档里**没有**等级字段。等级是游戏拿经验值 `Experience` 现算的，所以这边填等级，实际写进去的是换算后的经验。

```
累计经验 = floor(100 × (等级 − 1) ^ 1.73)        1 ~ 100 级
100 级以上每级固定 4971，上限 9999 级
```

怎么确定公式没错：游戏自己会渲染一张身份卡（存档目录里的 `IDCardRender0.png`），我 1 级的时候上面印的是 `等级 001 / 0/100`，也就是 1 升 2 要 100 经验。代进公式，2 级 = `100 × 1^1.73` = 100，对上了。另外社区流传的等级表里 3 级是 331、41 级是 59096，公式算出来一模一样。

网上还流传「100 级要 310714 经验」，跟公式差挺多（公式算 283432）。我信公式，那个数字不知道从哪传出来的。

写等级时特意**不写刚刚好的经验值**，而是取这一级的中间值：

```python
xp = (xp_for_level(L) + xp_for_level(L + 1)) // 2
```

公式毕竟是自己推的、不是从游戏里挖出来的原版，差几十点的话「刚刚好」可能就掉回上一级；取中间有半格容错。

100 级往上那段（每级 4971）误差可能更大，因为我没有那一段的数据点。界面上的「经验值」框可以手填，直接绕开公式。

## 命令行版

不想开界面的话：

```bash
python src/phasmo_save.py keys
python src/phasmo_save.py get PlayersMoney
python src/phasmo_save.py set PlayersMoney 999999999 --apply
```

不加 `--apply` 只生成一个 `.new` 文件，不动原件。

## 存档的加密方式

```
文件 = IV(16 字节) || AES-128-CBC(PKCS7(明文))

key = PBKDF2-HMAC-SHA1(密码, salt = IV, 迭代 100 轮, 输出 16 字节)
```

密码是 `t36gref9u84y7f43g`，在 `resources.assets` 的 `ES3Defaults` 资产里明文放着。这是 Easy Save 3 这个插件的默认密码，作者没改过。

**关键是 salt 就是 IV 本身。** 挺反直觉的，一般都当两个独立的东西。

## 怎么扒出来的

游戏是 Unity + IL2CPP，C# 已经编译成原生机器码，dnSpy 那一套没用，得上 Il2CppDumper。本机只有 .NET 10 而它要 .NET 6，加个 `DOTNET_ROLL_FORWARD=Major` 放行就行。

拿到 `dump.cs` 后能看到用的是 Easy Save 3，顺着找到 `ES3Internal.AESEncryptionAlgorithm`。Ghidra 跑不起来（本机 Java 只有 8），就用 capstone 自己写了段反汇编，把 `Decrypt` 的机器码读出来，拿到三个参数：

```
ivSize       = 16
keySize      = 16      # 也就是 AES-128，不是 256
pwIterations = 100
```

光有密码解不开。一开始按常见套路试了十几组（md5(密码) 当密钥、密码补零凑 16 字节之类）全错。真正定位到「salt = IV」靠的是读反汇编，不是猜。

`re-tools/` 里那两个 probe 脚本就是当时失败的尝试，一并留着。

机器上没有 pycryptodome，`src/aes.py` 是手写的 AES，支持 128/192/256 和 CBC/ECB，拿 FIPS-197 的标准向量验过。

## 走过的弯路

写在这免得以后重做时再踩一遍：

- 游戏**全混淆**了，方法名全是马拉雅拉姆文（像 `ഡതതള഻തജഢബ`），按名字搜代码完全没戏。
- 想通过 `Experience` 这个字符串反查谁在用——扫出 588 处引用，capstone 逐条验过都是真指令，但**每个类都有**（`Bloom`、`TarotCard`、`SaltSpot` 都中）。原因是 IL2CPP 会给每个方法生成一个元数据注册桩，跟业务逻辑无关。废了。
- 搜浮点常量 `1.73`，全盘只有一处，但它旁边是 `0.698132`、`1.22173`、`1.51844`——那是一张**角度转弧度表**（1.73 弧度 ≈ 99°）。假线索。
- 扫了 44 GB 游戏数据找经验值表，一无所获。说明经验是算出来的，不是查表。

## 已知问题

- **云存档会覆盖。** 游戏接了 Unity 的 CloudSave。如果进游戏发现进度被回滚，就是云端盖掉了本地。Steam 云同步也开着。
- 100 级以上的经验换算误差可能偏大（见上）。
- 游戏大版本更新后可能失效。要是作者哪天终于把默认密码换了，得照「怎么扒出来的」那节重做，主要就是改 `src/phasmo_save.py` 里的 `PASSWORD` 和 `PBKDF2_ITERS`。
- 只有 Windows 版。
